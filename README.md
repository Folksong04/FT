# FT ♥

เว็บบันทึกรอบเดือน (ปฏิทินรายเดือน / รายปี + สรุปจำนวนวัน) โทนความรัก เป็นเว็บไฟล์เดียว ไม่ต้องมีเซิร์ฟเวอร์

- `index.html` - หน้าเว็บ
- `data.json` - ข้อมูลที่ทุกคนเห็นร่วมกัน
- `.nojekyll` - ให้ GitHub Pages ส่งไฟล์ตามที่เป็น
- `manifest.json`, `icon-192.png`, `icon-512.png`, `apple-touch-icon.png` - ไอคอนสำหรับเพิ่มลงหน้าจอหลักมือถือ

## ใช้บนมือถือ

- หน้าเว็บปรับตามขนาดจอ ปัดซ้าย / ขวาบนปฏิทินเพื่อเปลี่ยนเดือน
- เพิ่มเป็นแอปบนหน้าจอหลัก
  - **iPhone (Safari):** ปุ่มแชร์ → "เพิ่มไปยังหน้าจอโฮม"
  - **Android (Chrome):** เมนู ⋮ → "เพิ่มลงในหน้าจอหลัก" / "ติดตั้งแอป"

## รหัสผ่าน

- ต้องใส่รหัสผ่านก่อนเข้าดูเว็บ (ถามรหัสจากเจ้าของเว็บ) ใส่ครั้งเดียวต่อการเปิดแท็บ กด "🔒 ล็อก" เพื่อล็อกใหม่
- รหัสผ่านไม่ได้เขียนไว้ในโค้ด แต่ `data.json` ถูกเข้ารหัส (AES-256-GCM, กุญแจจาก PBKDF2-SHA256 250,000 รอบ)
  คนที่เปิดไฟล์ `data.json` ตรง ๆ จะเห็นแค่ตัวอักษรที่อ่านไม่ออก
- ⚠ รหัส 4 หลักมีแค่ 10,000 แบบ คนที่ตั้งใจเดารหัสด้วยโปรแกรมยังเดาได้ ถ้าต้องการปลอดภัยกว่านี้ให้ใช้รหัสที่ยาวขึ้น
- ห้ามแก้ `data.json` ด้วยมือ ให้แก้ผ่านหน้าเว็บเท่านั้น

## ขึ้น GitHub Pages

1. สร้าง repository ใหม่บน GitHub (Public) เช่น `ft`
2. กด **Add file → Upload files** แล้วลากไฟล์ทั้ง 3 ไฟล์ในโฟลเดอร์นี้ขึ้นไป → **Commit changes**
   (ถ้าไฟล์ `.nojekyll` ไม่ขึ้น ไม่เป็นไร เว็บยังใช้งานได้)
3. ไปที่ **Settings → Pages** → Source: **Deploy from a branch** → Branch: `main` / `(root)` → **Save**
4. รอประมาณ 1-2 นาที จะได้ลิงก์ `https://<username>.github.io/ft/` ส่งลิงก์นี้ให้ใครก็ดูได้

## วิธีแก้ไขข้อมูล (เฉพาะเจ้าของเว็บ)

คนที่เปิดลิงก์จะดูได้อย่างเดียว ถ้าจะแก้ไขมี 2 วิธี

### วิธีที่ 1: บันทึกจากหน้าเว็บโดยตรง (แนะนำ)

1. สร้าง token ที่ GitHub → **Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token**
   - Repository access: **Only select repositories** → เลือก repo ของเว็บนี้
   - Permissions → Repository permissions → **Contents: Read and write**
2. เปิดเว็บ → กด **"✎ เจ้าของเว็บ: แก้ไข"** → ใส่ `username/repo`, branch `main` และ token → **เชื่อม GitHub**
3. ติ๊กวันที่มาและวันที่หายในปฏิทิน ระบบจะบันทึกลง `data.json` ใน repo ให้อัตโนมัติ
   คนอื่นจะเห็นข้อมูลใหม่ภายในประมาณ 1 นาที (กด "โหลดข้อมูลล่าสุด" หรือรีเฟรชหน้า)

token จะถูกเก็บไว้ในเบราว์เซอร์ของเครื่องที่ใส่เท่านั้น ไม่ได้อยู่ในไฟล์ของเว็บ กด "ออกจากโหมดแก้ไข" เพื่อลบ token ออกจากเครื่อง

### วิธีที่ 2: แก้ในเครื่องแล้วอัปโหลดเอง

1. กด **"✎ เจ้าของเว็บ: แก้ไข"** → **แก้ในเครื่อง** → ติ๊กปฏิทิน
2. กด **"⬇ ดาวน์โหลด data.json"** แล้วอัปโหลดไฟล์นี้ไปทับ `data.json` เดิมใน repo
